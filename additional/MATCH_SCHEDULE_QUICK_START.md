# Match Schedule - Quick Start Guide

## 🚀 How to Access

1. Navigate to any tournament detail page
2. Tournament must be in **'closed'**, **'ongoing'**, or **'completed'** status
3. Click on the **"Match Schedule"** tab
4. View all matches organized by rounds

## 👤 For Tournament Organizers

### View Matches
- Matches are grouped by rounds (Round 1, Quarter-Final, Semi-Final, Final)
- Each match shows:
  - Participant names
  - Date and time
  - Venue and court
  - Status badge
  - Winner (if completed)

### Reschedule a Match
1. Click the **pencil icon** (Edit) on the match
2. Select new date and time
3. Click **"Reschedule"**
4. Match updates immediately

### Cancel a Match
1. Click the **X icon** on the match
2. Read the warning message
3. Enter a reason for cancellation
4. Click **"Cancel Match"**
5. Match status changes to 'Cancelled'

### Filter Matches
1. Click **"Filters"** button
2. Select status (All, Scheduled, In Progress, etc.)
3. Select round
4. Matches update automatically

### Refresh Data
- Click **"Refresh"** button to reload all matches
- Data auto-refreshes after reschedule/cancel operations

## 📊 Match Status Badges

| Badge Color | Status | Meaning |
|------------|--------|---------|
| 🔵 Blue | Scheduled | Match is scheduled but not started |
| 🟢 Green | Ready | Both participants checked in |
| 🟡 Yellow | In Progress | Match is currently being played |
| 🟢 Emerald | Completed | Match finished with result |
| 🔴 Red | Cancelled | Match was cancelled |
| 🟠 Orange | Postponed | Match was postponed |
| 🟣 Purple | Walkover | Match won by walkover |

## ⚠️ Important Notes

### Permissions
- Only **tournament organizers** can reschedule or cancel matches
- Participants can **view** the schedule but cannot edit
- **Completed matches** cannot be rescheduled or cancelled
- **Cancelled matches** cannot be edited

### Reschedule Restrictions
- New date must be **today or in the future**
- If a court is assigned, system checks **court availability**
- Cannot reschedule **completed** or **cancelled** matches

### Cancel Warnings
- Cancelling a match affects the **tournament bracket**
- Cancellation reason is **visible to participants**
- Action **cannot be undone**

## 🎯 Common Tasks

### Schedule an Unscheduled Match
If a match shows "This match needs to be scheduled":
1. Click the **pencil icon**
2. Select date and time
3. Click **"Reschedule"**

### Change Match Time
1. Click **pencil icon** on the match
2. Keep same date, change time
3. Click **"Reschedule"**

### Change Match Date
1. Click **pencil icon** on the match
2. Select new date
3. Adjust time if needed
4. Click **"Reschedule"**

### View Specific Round
1. Click **"Filters"**
2. Select round from dropdown
3. Only that round's matches will show

### View Only Scheduled Matches
1. Click **"Filters"**
2. Select **"Scheduled"** from status dropdown
3. View only upcoming matches

## 🔄 Tab Navigation

The tournament detail page has 3 tabs:

1. **Overview** - Shows participants list
2. **Match Schedule** - Shows all matches (NEW)
3. **Bracket** - Shows tournament bracket

Click any tab to switch views.

## 📱 Mobile Support

The match schedule is fully responsive:
- Swipe to view tabs on mobile
- Tap match cards to view details
- All actions work on touch devices

## 🆘 Troubleshooting

### "No Matches Found"
- Brackets may not be generated yet
- Try adjusting filters
- Click refresh button

### Can't See Edit/Cancel Buttons
- Verify you are the tournament organizer
- Check if match is already completed
- Ensure tournament is in correct status

### Reschedule Fails
- Check if new date is in the past
- Verify court availability
- Ensure match is not completed

### Cancel Fails
- Verify you are the organizer
- Check if match is already completed
- Ensure reason is provided

## 📞 Need Help?

If you encounter issues:
1. Refresh the page
2. Check your internet connection
3. Verify you're logged in as organizer
4. Contact support if problem persists
