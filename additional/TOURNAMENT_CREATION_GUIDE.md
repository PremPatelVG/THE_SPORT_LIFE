## **PHASE 1: CREATE TOURNAMENT**

### **Step 1: Navigate to Create Tournament**
```
1. Login to your account
2. Go to Dashboard/Home page
3. Click "Create Tournament" button
```

### **Step 2: Fill Tournament Details**

#### **Basic Information:**
```
Tournament Name: "Badminton Championship 2025"
Description: "Singles knockout tournament"
Sport: Select "Badminton" from dropdown
Category: Select "Singles"
```

#### **Tournament Format:**
```
Format Type: "Knockout" (or "Single Elimination")
```

#### **Participant Limits:**
```
Min Participants: 4
Max Participants: 4
```
**Important:** For knockout, use powers of 2 (2, 4, 8, 16, 32)

#### **Registration Period:**
```
Registration Start: Today (e.g., Oct 27, 2025)
Registration End: Tomorrow (e.g., Oct 28, 2025)
```

#### **Tournament Dates:**
```
Start Date: Oct 29, 2025
End Date: Oct 30, 2025
```

#### **Venue:**
```
Venue: Select from dropdown (e.g., "Horizon Adventure Park")
```

#### **Financial (Optional):**
```
Entry Fee: 0.00 (or set amount like 100.00)
Prize Money: 0.00 (or set amount like 5000.00)
```

### **Step 3: Submit**
```
Click "Create Tournament" button
Wait for success message
Tournament created! ✅

## **PHASE 2: REGISTRATION (Get 4 Players)**

### **Step 4: Share Tournament**
```
1. Copy tournament link/ID
2. Share with players
3. Players register individually
```

### **Step 5: Player Registration (Each Player)**

**Player 1 Registration:**
```
1. Player logs in
2. Goes to tournament detail page
3. Clicks "Register" button
4. Confirms registration
5. Status: Registered ✅
```

**Repeat for Players 2, 3, 4**

### **Step 6: Verify Participants**
```
As organizer:
1. Go to tournament detail page

   - Player 1

## **PHASE 3: CLOSE REGISTRATION & GENERATE BRACKETS**

### **Step 7: Close Registration**
```
1. Go to tournament detail page
2. Scroll to "Tournament Management Panel"
3. See message: "4/4 participants registered"
4. Click "Close Registration" button
5. Confirm the action
6. Wait for processing...
```

### **Step 8: System Generates Brackets**
```
Automatic process:
1. Status changes: "open" → "closed"
2. System creates bracket structure
3. Matches generated:
   - Semi-Final 1: Player 1 vs Player 2
   - Semi-Final 2: Player 3 vs Player 4
   - Final: Winner SF1 vs Winner SF2
4. Total: 3 matches created ✅
```

### **Step 9: Start Tournament**
```
1. Click "Start Tournament" button
2. Status changes: "closed" → "ongoing"
3. Tournament is now active! ✅
```

## **PHASE 4: SCHEDULE MATCHES**

### **Step 10: Navigate to Bracket Tab**
```
1. Go to tournament detail page
2. Click "Bracket" tab
3. See 3 matches:
   - Round 1 (Semi-Finals): 2 matches
   - Round 2 (Final): 1 match
```

### **Step 11: Option A - Bulk Schedule (Recommended)**

**Click "Bulk Schedule" Button:**
```
1. Purple button in top-right
2. Modal opens
```

**Fill Schedule Parameters:**
```
Start Date: Oct 29, 2025
Start Time: 09:00
Match Duration: 60 minutes
Break Duration: 15 minutes
Venue: Select venue
Matches per Day: 3
```

**Generate Schedule:**
```
1. Click "Generate Schedule" button
2. Preview appears:
   
   Oct 29, 2025:
   - 09:00 AM - Semi-Final 1
   - 10:15 AM - Semi-Final 2
   - 11:30 AM - Final
```

**Save Schedule:**
```
1. Review preview
2. Click "Save Schedule" button
3. All 3 matches scheduled! ✅
```

### **Step 12: Option B - Individual Schedule (Alternative)**

**Go to Match Schedule Tab:**
```
1. Click "Match Schedule" tab
2. See unscheduled matches
```

**Schedule Each Match:**
```
For each match:
1. Click "Schedule Now" button
2. Select date: Oct 29, 2025
3. Select time: 09:00 AM (then 10:15 AM, etc.)
4. Click "Reschedule"
5. Match scheduled ✅
```

## 💡 **Important Tips**

### **Participant Numbers:**
```
Knockout tournaments work best with powers of 2:
✅ 2 players = 1 match (Final only)
✅ 4 players = 3 matches (2 SF + 1 F)
✅ 8 players = 7 matches (4 QF + 2 SF + 1 F)
✅ 16 players = 15 matches (8 R1 + 4 QF + 2 SF + 1 F)

❌ 3, 5, 6, 7 players = Need byes or different format
```

### **Scheduling:**
```
Match Duration: 60 minutes (typical for badminton)
Break Duration: 15 minutes (between matches)
Matches per Day: 3-4 (for 4-player tournament)

Total Time Needed:
- 3 matches × 60 min = 180 min
- 2 breaks × 15 min = 30 min
- Total: 210 min (3.5 hours)
```

### **Best Practices:**
```
1. Schedule semi-finals on same day
2. Allow break before final
3. Have backup court ready
4. Prepare scoring sheets
5. Assign referee if available
6. Test equipment before start
```
